A native Android carpooling application designed to help university students share rides, reduce daily commute costs, and connect effortlessly. Built with Android Studio, Firebase, and Google Maps API, the app provides real-time ride matching, route visualization, and an integrated in-app messaging system.

Key Features

Student Authentication & Profiles: Secure login and registration tailored for campus students.

Ride Creation & Scheduling: Student drivers can post available seats, departure times, pickup locations, and split-cost rates.

Route Search & Matching: Passengers can search for available drivers along their specific commute routes.

Google Maps Integration: Visual route plotting, pin drop location selection, and distance estimation using the Google Maps SDK.

Built-in Real-Time Messaging: Direct 1-on-1 chat system allowing drivers and passengers to coordinate pickup details without leaving the app.

Real-Time Status Updates: Instant notifications and database sync when a ride is requested, accepted, or completed.

Tech Stack & Dependencies

Platform: Native Android (Android SDK)

Languages: Java / Kotlin

IDE: Android Studio

Backend & Database: Firebase Authentication, Firebase Realtime Database

APIs & SDKs: Google Maps Android SDK, Google Places API

UI Architecture: Material Design Components, XML Layouts
